# Daggerfall Unity import inputs

Unmodified copies of the [Daggerfall Unity](https://github.com/Interkarma/daggerfall-unity) files the
import and its tests read, at their Daggerfall Unity paths, under the MIT licence in `LICENSE`
(Daggerfall Workshop). The import commands cite them as `daggerfall-unity/<path>`. Refresh a file by
copying it from a Daggerfall Unity checkout; the importer revision covers this directory, so a changed
file asks for a re-import.
